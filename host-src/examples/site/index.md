# Welcome to the playground

![A picture from jeffrey.io, imported as an attachment](HERO_IMAGE)

This site is **content**, not code: markdown pages, HTML fragments, and templates in the
tenant's content tree, written over MCP and rendered by the host. Nothing here runs in a
box except the [guestbook](/guestbook), which keeps its entries in the tenant's own
database.

| page | what it shows |
| --- | --- |
| [Blog](/blog) | A listing with paging, tags, and an [Atom feed](/blog/feed.xml) |
| [Notes](/notes) | A directory with no index page, listed by the `directory` template |
| [About](/about) | An HTML fragment wrapped in the site's layout |
| [Playground](/playground) | A whole HTML document, served exactly as written |
| [Members](/members) | A page only signed-in people can read |
| [Attachments](/attachment/) | Upload images (as an owner) |

- [x] Templates with layouts and partials
- [x] Images over MCP or upload
