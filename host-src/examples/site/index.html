goober playground

This page is static content for the tenant playground, written through the operator MCP and persisted under storage/content/playground/.

  • /hello/sensei: a Rust box saying hello
  • /roll/20: roll a d20 with replayable randomness
  • /echo/anything?q=1: what a box sees
  • /nowhere: the error page

Identity

  • Sign in with an emailed code (local mode prints it in the host's terminal)
  • /identity/account: who you are, your roles, and sign out
  • /whoami: any signed-in user; the box sees user
  • /owners-room: only owner or a host:owner operator
