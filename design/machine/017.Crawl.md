# Crawling

> Status: machine-authored and **not ratified**. Recorded on 2026-10-27. It builds the first
> version of `design/human/800.Crawl.md` (drafted by Claude at the human's request, for the
> human to own): a polite robot in the host, views that simplify pages, background crawls for
> operators, and a `web` service boxes call. The code is the `web` package (URLs, robots.txt,
> the HTML parser and views) and `host/src/web_fetch.cpp` and `crawler.cpp`. Where it departs
> from 800, §8 says so.

## 1. The robot

Every fetch, for anyone, goes through one `WebFetcher`:

| rule | how |
| --- | --- |
| robots.txt | Fetched per origin before anything else and kept a day (ten minutes after a failure). RFC 9309: our product token `goober`'s groups merged, else `*`; the longest match wins and ties allow; a 4xx means no rules and a 5xx or no answer means stay out. Crawl-delay is honored up to 60 s. |
| who it is | `User-Agent: goober/<version> (+<web.contact or the public URL>; a polite robot that reads robots.txt)`. |
| pacing | One request per origin at a time, at least `web.min-delay-ms` apart (default 2 s), or the site's Crawl-delay if longer. A 429 or 503 backs the origin off for its Retry-After (60 s without one, an hour at most). Turns are booked before sleeping, so concurrent callers queue. |
| public addresses only | The host resolves every name itself and refuses loopback, private, link-local, shared (100.64/10), multicast, documentation, and reserved addresses, IPv4 and IPv6 (mapped, 6to4, Teredo, NAT64 too), then connects to the address it checked (`curl --resolve`), so a second DNS answer can't redirect it. Only ports 80 and 443. Every redirect hop is checked again, at most five. Local mode lifts the address and port rules, for development and tests. |
| bounded | A page is at most `web.max-page-bytes` (4 MiB) after decompression; only text-like types are read (HTML, XHTML, text, JSON, XML, feeds); 15 to 30 s per fetch. |
| cached | Pages are kept in `storage/web/web.db` by URL. A copy younger than the caller's `max_age_ms` is served as it is; an older one is revalidated with `If-None-Match` and `If-Modified-Since`, and a 304 costs the site nothing. |
| text | Latin-1 and Windows-1252 (by header or `<meta charset>`) are converted; anything else invalid as UTF-8 becomes U+FFFD. |
| opt-out | `web.opt-out` in the config and the `web_optout` tool: hosts (and their subdomains) never fetched. |
| audited | Every request is a line in `logs/egress.log` with service `web`. |

## 2. Views

`page_views` turns a page into what a caller asked for (800 § What a page becomes):

| view | gives |
| --- | --- |
| `html` | The page as fetched, in UTF-8. |
| `text` | Visible text: scripts, styles, `head`, and the like left out; blocks on their own lines; `pre` kept. |
| `markdown` | Headings, paragraphs, emphasis, links and images (absolute), nested lists, quotes, code, and pipe tables. |
| `links` | Every `a href`, absolute (plus `mailto:` and `tel:`), with text and `rel`, deduplicated. |
| `meta` | Title, description, keywords, robots, canonical, language, icon, Open Graph and Twitter fields, feeds, generator, and `platform`: shopify, woocommerce, wordpress, squarespace, wix, square, bigcommerce, webflow, localline, barn2door, grazecart, harvie, and others, from the generator and the scripts and stylesheets a page loads. |
| `jsonld` | Every `application/ld+json` block, parsed, with `@graph` flattened. |
| `tables` | Each table's caption, headers (a first row of `th`, or `thead`), and rows. |
| `json` | The body parsed, for JSON endpoints like a Shopify store's `/products.json`. |
| `select` | Elements matching a CSS selector: tag, text, attributes, and HTML. |
| `extract` | `{"items": selector, "fields": {name: "sel" or "sel@attr" or "@attr" or ""}}`: one record per item. `href` and `src` come back absolute. |

The parser is tolerant rather than standard: implied ends for `p`, `li`, `dt`/`dd`, table
parts, `option`, and headings; end tags close only within their scope (a stray `</div>` in a
cell stays in the cell); raw text for `script` and `style`. It is bounded at depth 256 and
200,000 nodes, and selector matching is memoized, so a hostile page or selector costs bounded
work. The `web` package's tests cover each view on a realistic page, and the fuzz package
mutates every parser in it.

Selectors support type, `*`, `#id`, `.class`, `[attr]`, `[attr=v]`, `~=`, `|=`, `^=`, `$=`, `*=`,
`:first-child`, `:last-child`, `:nth-child(n)`, descendant and `>` combinators, and commas.
`+`, `~`, and other pseudo-classes are refused by name.

## 3. Operators and their agents

| tool | does |
| --- | --- |
| `web_fetch` | One page with views, `select`, and `extract`; `max_age_ms` 0 fetches again. |
| `crawl_start` | A background crawl: `seeds`, `scope` (`site`: the seeds' sites, `www.` or not; `prefix`: URLs starting with `prefixes`), `include` and `exclude` globs, `max_pages` (100, at most 5000), `max_depth` (3, at most 10), `sitemaps`, and `extract`. |
| `crawl_list`, `crawl_stop`, `crawl_rerun` | Crawls with counts; stop one; run one again from its seeds (refetching, conditionally). |
| `crawl_pages` | Each URL's state (pending, done, error), status, title, and error. |
| `crawl_records` | JSON-LD items by `@type` and extract records (`kind: extract`), with their page. |
| `web_optout` | The never-fetch list, and the User-Agent the robot sends. |

A crawler thread takes one page per running crawl per step, from the shallowest pending ones,
skipping any whose site isn't ready yet, so several crawls share the robot without anyone
waiting on one slow site. It follows links in scope, but not `rel=nofollow` links or pages
whose robots meta says `nofollow`; a page whose robots meta says `noindex` yields no records.
Sitemaps (`/sitemap.xml` per seed, and sitemap indexes) add their in-scope URLs.

Crawls live in `storage/web/web.db` (`crawls`, `frontier`, `records`), host-wide, since
crawls are the operator's; boxes keep what they find in their own databases.

## 4. Boxes

A box declares the web as a service and names the hosts it may read:

```json
"external": {
	"farms": {
		"web": { "hosts": ["*"] },
		"methods": { "fetch": { "budget": { "calls": 5 } } }
	}
}
```

`hosts` holds names (`ranch.example`, which also covers `www.ranch.example`), `*.name` for
subdomains, or `*`. `fetch` is the one method (budget 1 to 100 per call, default 10). The call:

```
goober_call("farms", "fetch", {"url", "views", "select", "extract", "max_age_ms"})
-> {"url", "status", "content_type", "fetched_at", "from_cache", "redirects", ...views}
   or {"error", "retry_after_ms"?}
```

The fetch never outlives the request: waiting for a site's turn counts against the box's own
timeout, and a turn that can't come in time answers with `retry_after_ms`. A domain-specific
crawler is an ordinary box: its sources, frontier, and inventory are its own tables (shared
across domains with a fixed `tenant`, 008 §4), and a timer walks them a few pages per fire.

## 6. Tests

`web/test`: URL parsing and resolution, robots.txt groups and matching, every view on a
ranch's page, selectors and their refusals, and hostile input. `host/test/web_test.cpp`, against
a small site run by the test: address classification; robots.txt first and obeyed; the
User-Agent; the cache and a conditional refetch; redirects; Latin-1; images refused; pacing
between every request; the egress log; opt-out; a crawl with sitemaps, scope, nofollow, a
robots-refused page, JSON-LD and extract records, rerun, and stop; and a box fetching with
views, refused a host its manifest doesn't list.

## 7. What it costs a site

At the defaults, at most one request every two seconds per site, robots.txt once a day, and
nothing for an unchanged page within the caller's `max_age_ms`. A crawl of 100 pages on one site
takes over three minutes, by design.
