# Internal Routes

> Status: machine-authored and **not ratified**. Recorded on 2026-10-26. It builds the
> synchronous half of `039.InternalMessaging.md`: internal routes that only named boxes can
> reach, called through `goober_call` like an external service. The code is
> `routes.internal` and `external.$label.box` in `manifest`, `check_calls` in
> `host/src/data_tools.cpp`, and `internal_call` in `host/src/network.cpp`. Where it departs
> from 039, §5 says so, and the human doc wins until it is updated.

## 1. Declaring

The callee:

```json
{
	"box": "billing",
	"types": "billing.openapi.json",
	"routes": {
		"internal": {
			"/jobs/{job_id : int64}/invoices": {
				"post": {
					"name": "create_invoice",
					"callers": ["jobs"],
					"requirements": [["owner"]],
					"body": "json:InvoiceRequest",
					"response": "json:Invoice"
				}
			}
		}
	}
}
```

The caller:

```json
{
	"box": "jobs",
	"external": {
		"billing": { "box": "billing", "methods": { "create_invoice": { "budget": { "calls": 2 } } } }
	}
}
```

- An internal route is HTTP-shaped (path, verb, `body`, `query`, `response`) with a
  required `callers` list of box names. `public` is refused, since nothing outside can
  reach it; `requirements` are optional. It is never in the HTTP route table.
- A caller names a box instead of a base, and its methods are the callee's route names, with
  a budget. `effect: outbox` to a box isn't built yet (§5).

## 2. Both sides agree, and nothing loops

At every upload and promotion, the host checks every box as it would be with the new
version in place:

- every box service names a deployed box, other than itself;
- every method is an internal route of that box, whose `callers` list the calling box;
- the call graph has no cycle.

So the callee goes first; a caller can't depend on a box quietly, and a callee can't drop a
caller that depends on it. The host also caps a chain of calls at four deep at runtime.

## 3. A call

`goober_call("billing", "create_invoice", {"path": {"job_id": "42"}, "query": {...}, "body":
{...}})`:

1. The route is found and its callers checked again (a version can be promoted back).
2. The path is built from the route's own pattern; each parameter must match its type.
3. **Authority never grows** (039 § Whose call is it?): the callee's requirements are checked
   against the person the caller's request was made for. Someone who isn't an owner gets
   `{"status": 403}` back, whatever the calling box could do.
4. The body and query are checked against the callee's types, as a request from outside would
   be; a failure is `{"status": 400, "error"}`.
5. The callee runs in its own call, with the caller's tenant, domain, and user, and
   `"caller": {"box", "route", "request_id"}` in its request document (`!caller_box`,
   `!caller_route`).
6. **Deadlines only shrink:** its timeout is the smaller of its own and what's left of the
   caller's.
7. Its writes commit on their own, when it answers below 500, even if the caller later fails
   (039 § Calls and commits).
8. The caller gets `{"status", "content_type", "body", "json"}`, or `{"status": 5xx, "error"}`
   when the callee failed. The hop is an access-log line with path `internal:billing/...`.

## 4. Tests

`host/test/internal_test.cpp`: a caller refused before its callee exists; an owner's call
carrying the path, typed body, caller, and person across; a non-owner refused through the
caller; a route without requirements serving a public caller; internal routes unreachable
from outside; a callee version that drops its caller refused; a loop refused.

## 5. Departures and what is missing

| doc | section | v1 says |
| --- | --- | --- |
| 039 | Calling an internal route | The box reads JSON through `goober_call`; there are no generated typed functions. |
| 039 | Calls and commits | No outbox elements addressed to a box yet; calls are synchronous only. |
| 039 | Idempotent internal routes | `idempotent` is accepted with a warning and not implemented. |
| 039 | Binding to a tenant | The tenant is always the caller's; a path argument can't choose another tenant's database. |
| 039 | Wrapping an external service | Redirecting an OpenAPI service to an adapter box waits for OpenAPI documents (015 §7). |
| 039 | Time, budgets, and loops | The checker doesn't add up worst cases across boxes yet. |
| 045 | Calling into an internal service | Timers can't `target` an internal route yet. |
